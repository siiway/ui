# @siiway/ui-core

SiiWay's design tokens, theme maths and UI strings, for any framework. No
dependencies.

- Neutral greys, radii and shadows as Fluent token names (`NEUTRAL`, `RADII`,
  `SHADOWS`, `themeOverrides(scheme)`), and the page canvas (`CANVAS`).
- The 16-shade brand ramp around an accent, with the accent at shade 80
  (`brandRamp(accent)`).
- The library's own strings in English and Chinese (`pickStrings(locale)`).

For React, use [`@siiway/ui-react`](https://www.npmjs.com/package/@siiway/ui-react),
which builds on this package. Documentation:
https://ui.siiway.org
