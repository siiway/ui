## Strings

Text you show comes in as props: you translate it, the library renders it.
The library owns only a few strings of its own: copy feedback, pagination,
show/hide password, the colour picker's labels, the theme switch, the search
button and the command palette's key hints, the outline's heading, and
`aria-label`s. Those ship in English and Chinese.

### Choosing the language

Pass your app's current language to `<UiProvider locale>`. Any `zh` tag
(`zh`, `zh-CN`, `zh-Hans-TW`) gives Chinese; anything else, or nothing, gives
English.

```tsx
<UiProvider scheme="light" locale={i18n.language}>
```

### Changing a string

`strings` replaces single strings; the rest stay as shipped:

```tsx
<UiProvider scheme="light" locale="en" strings={{ copied: "Copied" }}>
```

Strings that fill in a value are functions:

```ts
strings={{ totalItems: (count) => `${count} rows` }}
```
