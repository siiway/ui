A search box drawn as one field: the icon, the input and whatever you put
after it (a spinner, a clear button) share one border and one focus ring.

It takes Fluent `Input`'s props, and passes a `ref` to the input. `className`
goes on the field. To filter a list,
[`ListSearch`](?path=/docs/lists-and-data-datalist--docs) is the smaller box
with a clear button built in.
