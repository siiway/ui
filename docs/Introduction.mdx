The look of SiiWay's apps, as packages. Every component in these docs is
live, and you can use it. The menus at the top of each component's page set
its examples' theme, light or dark (the whole site follows), the language,
English or Chinese (the library's own strings and the examples' text, as
your app's `locale` would), and the direction, left to right or right to
left.

<Canvas of={PageHeader.Default} />

Two packages:

- **`@siiway/ui-core`**: the design tokens (neutral greys, radii, shadows, the
  page canvas), the brand-ramp maths and the library's own strings in English
  and Chinese. No dependencies and no framework, so any stack can use it.
- **`@siiway/ui-react`**: the React + Fluent UI v9 layer: `createTheme`,
  `<UiProvider>`, hooks, and the components on top.

## Install

```bash
bun add @siiway/ui-react @siiway/ui-core
```

`@siiway/ui-react` uses your app's own copies of `react`, `react-dom`,
`@fluentui/react-components` and `@fluentui/react-icons` (peer
dependencies), so there is only one of each in your bundle. It works with
React 18.3 and 19.

## Set up

Wrap the app in `<UiProvider>`, where `<FluentProvider>` used to be. With
React Router:

```tsx
import {
  ThemeSwitch,
  UiProvider,
  useThemeMode,
  type UiRouter,
} from "@siiway/ui-react";
import { Link, useNavigate } from "react-router-dom";

// Defined once, outside any component, so it stays the same object.
const router: UiRouter = { Link, useNavigate };

export function Root() {
  const { mode, setMode, scheme } = useThemeMode();
  return (
    <UiProvider
      page
      scheme={scheme}
      locale={navigator.language}
      router={router}
    >
      <ThemeSwitch value={mode} onChange={setMode} />
      <App />
    </UiProvider>
  );
}
```

`useThemeMode` keeps the light or dark choice, and follows the OS for
`system`. `page` makes the provider the page: the canvas colour behind
everything, no body margin, thin scrollbars in the scheme, and selected text
tinted with the accent. So that a dark page doesn't flash white while the
app loads, add the boot script to `<head>`:
see [Light and dark](?path=/docs/guides-theme--docs).

| Prop          | What it does                                                                                                                                                                                 |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `scheme`      | `"light"` or `"dark"`: `useThemeMode().scheme`, or your app's own. The provider only draws it.                                                                                               |
| `page`        | On the outermost provider: it and the page take the canvas colour, in the scheme. See [Theme](?path=/docs/guides-theme--docs).                                                               |
| `accent`      | Brand colour, `#rgb` to `#rrggbbaa`. Missing or invalid gives Fluent's blue `#0078d4`. See [Theme](?path=/docs/guides-theme--docs).                                                          |
| `locale`      | A BCP-47 tag for the library's own strings: any `zh` tag is Chinese, anything else English. See [Strings](?path=/docs/guides-strings--docs).                                                 |
| `strings`     | Replaces single library strings.                                                                                                                                                             |
| `router`      | How links and navigation work. Without one, links are `<a href>`. See [Router](?path=/docs/guides-router--docs).                                                                             |
| `onPageTitle` | Called with a page's title when its `PageHeader` or `DetailHeader` mounts (`tabTitle`, or the title if it's plain text), and with `null` when the page goes, so you can set the tab's title. |
| anything else | Passed to `FluentProvider` (`style`, `className`, `dir`, …).                                                                                                                                 |

## Server rendering

Every component renders on the server. Use Fluent's usual SSR setup
(`RendererProvider`, `SSRProvider`, `renderToStyleElements`) around
`<UiProvider>`. Pass the scheme you rendered with so the client hydrates to
the same theme. `useThemeMode` can't know the person's choice on the server:
see [On the server](?path=/docs/guides-theme--docs).
